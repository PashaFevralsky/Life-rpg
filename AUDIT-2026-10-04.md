## Что намеренно не объявлено ошибкой

- Web/PWA остаётся 13.9.1, Android преобразуется в 14.0.3-rc.N. Это явно заданная политика `android-release-prepare.mjs`, а не случайное расхождение версии.
- Android source contract tests уже запускались отдельными шагами workflow. Теперь они также добавлены в `npm test` для одинаковой локальной проверки; прежний CI не был лишён этих тестов.
- Исторические тесты закреплённых релизов 12.x/13.8 и отключённого Secure AI Bridge не являются актуальными release gates. Их падение при прямом запуске само по себе не означает регрессию текущего приложения.
- Локальная проверка Android использовала `GITHUB_RUN_NUMBER=19` только как вход для преобразования assets. Это **не означает**, что GitHub Actions run 19 или новый подписанный APK уже опубликован.

## Применение и оставшаяся приёмка

Изменения подготовлены в локальной ветке. Публикация PR заблокирована: GitHub connector вернул HTTP 403 (Resource not accessible by integration), а локальный Git не имеет авторизации push. Для применения предоставляется ZIP с изменёнными файлами. Текущая main и установленный APK этим аудитом не обновляются автоматически. После принятия PR нужны обычная release-сборка и установка нового APK поверх RC18 с сохранением данных.

На устройстве остаётся проверить: обновление без потери пользовательской базы, настоящий экран с клавиатурой, выдачу разрешений и фоновые уведомления. Свежая резервная копия поможет также проверить реальные финансовые данные и нестандартные старые записи. Проверка импортов на синтетических данных не заменяет эту приёмку.
