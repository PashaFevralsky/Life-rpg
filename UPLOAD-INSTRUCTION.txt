Life RPG 5.2.2 — Budget Engine + Screenshot Import

Загрузка на GitHub с телефона:
1. Сделайте Экспорт JSON из текущей версии.
2. Распакуйте этот ZIP.
3. Откройте репозиторий PashaFevralsky/Life-rpg, ветка main.
4. Add file → Upload files.
5. Выберите ВСЕ файлы из этой папки и загрузите их в корень репозитория.
6. Commit message: Update Life RPG to 5.2.2 Budget Engine
7. Commit changes.
8. Подождите 1–3 минуты и откройте GitHub Pages.

Что нового:
- регулярные обязательные платежи с датами и автосопоставлением;
- эти платежи участвуют в автопилоте и cash-flow;
- перенос остатков конвертов в следующий месяц;
- OCR-импорт нескольких скриншотов банковских операций;
- очередь проверки суммы/даты/типа/категории перед записью;
- переводы между своими счетами не считаются доходом/расходом;
- импорт истории после сверки денежного баланса не искажает текущий остаток;
- после подтверждённого импорта Money Engine может автоматически перераспределить деньги.

Важно: OCR использует Tesseract.js из CDN, поэтому для распознавания нужен интернет. Изображения обрабатываются в браузере.
