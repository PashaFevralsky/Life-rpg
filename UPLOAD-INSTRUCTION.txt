Life RPG 5.2 — загрузка на GitHub с телефона

1. Распакуйте ZIP на телефоне.
2. Откройте GitHub → PashaFevralsky/Life-rpg → ветка main.
3. Add file → Upload files.
4. Выберите ВСЕ файлы из распакованной папки. Загружайте содержимое папки, а не саму папку.
5. Файлы index.html, app.js, styles.css, sw.js, manifest.webmanifest и иконки должны заменить старые файлы в КОРНЕ репозитория.
6. Commit message: Update Life RPG to 5.2 Financial Autopilot
7. Commit changes прямо в main.
8. Подождите 1–3 минуты и откройте https://pashafevralsky.github.io/Life-rpg/
9. В приложении откройте Ещё и проверьте: Life RPG 5.2.0.

Перед обновлением, если уже внесены реальные данные, сделайте Экспорт JSON в разделе Ещё.
Не очищайте данные сайта без резервной копии: локальные данные PWA хранятся в IndexedDB браузера.
