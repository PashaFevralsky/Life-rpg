Life RPG 7.0 — UX Rebuild

Что изменилось:
- мобильная навигация внутри каждого раздела вместо одной длинной страницы;
- Финансы разделены на Обзор / Обновить / Операции / Долги / План / Активы;
- единый быстрый плюс для частых действий;
- компактный главный экран и финансовый пульс;
- формы работы/тенниса/CRM сворачиваются;
- текущая финансовая модель и данные v14 сохраняются;
- OCR Hotfix 6.2.1 включён.

Загрузка с телефона:
1. Перед обновлением: Ещё → Настройки → Данные, версия и резервные копии → Экспорт JSON.
2. Распаковать ZIP.
3. GitHub → PashaFevralsky/Life-rpg → main → Add file → Upload files.
4. Выбрать файлы ВНУТРИ папки, не саму папку.
5. Заменить файлы в корне репозитория.
6. Commit message: Update Life RPG to 7.0 UX Rebuild
7. Подождать 1–3 минуты и открыть GitHub Pages.
8. Проверить в Ещё → Настройки, что версия Life RPG 7.0.0 и данные v14.
