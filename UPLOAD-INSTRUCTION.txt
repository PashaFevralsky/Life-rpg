Life RPG 7.0.1 — Cache Sync Hotfix

Что исправлено:
- устраняет смешанную загрузку интерфейса 7.0 с app.js 6.2.1;
- app.js, styles.css и manifest получают versioned URL;
- service worker тоже регистрируется с версией;
- «Проверить обновление» теперь проверяет удалённый APP_VERSION с cache:no-store и при необходимости перезагружает приложение с cache-buster;
- данные v14 и IndexedDB не меняются.

Загрузка с телефона:
1. Перед обновлением: Ещё → Настройки → Данные, версия и резервные копии → Экспорт JSON.
2. Распаковать ZIP.
3. GitHub → PashaFevralsky/Life-rpg → main → Add file → Upload files.
4. Выбрать 8 файлов ВНУТРИ папки, не саму папку.
5. Заменить файлы в корне репозитория.
6. Commit message: Update Life RPG to 7.0.1 Cache Sync Hotfix
7. Подождать 1–3 минуты и открыть GitHub Pages.
8. Полностью закрыть установленную PWA и открыть снова.
9. Проверить в Ещё → Настройки: Life RPG 7.0.1 • данные v14.
