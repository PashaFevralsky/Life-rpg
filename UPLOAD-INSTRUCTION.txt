Life RPG 6.2 — Financial OS

Перед обновлением: Ещё → Экспорт JSON.

Загрузка с телефона:
1. Распакуйте ZIP.
2. Откройте PashaFevralsky/Life-rpg на GitHub и выберите main.
3. Add file → Upload files.
4. Выберите ВСЕ файлы внутри распакованной папки, а не саму папку.
5. Файлы должны лежать в корне репозитория: index.html, app.js, styles.css, sw.js, manifest.webmanifest, icon-192.png, icon-512.png, UPLOAD-INSTRUCTION.txt.
6. Commit message: Update Life RPG to 6.2 Financial OS
7. Commit directly to main.
8. Подождите 1–3 минуты и откройте GitHub Pages.
9. В Ещё проверьте Life RPG 6.2.0 • схема данных v14.

После обновления обязательно откройте каждый долг и заполните «Следующий платёж» и «Следующая дата платежа». Для кредиток режим — «по выписке», для обычного кредита — «фиксированный».
