Life RPG 6.0 — Consolidated Life OS

Как загрузить на GitHub с телефона:
1. В текущей версии Life RPG: Ещё → Экспорт JSON. Сохраните копию.
2. Скачайте ZIP и распакуйте.
3. GitHub → PashaFevralsky/Life-rpg → ветка main.
4. Add file → Upload files.
5. Выберите ВСЕ 8 файлов из распакованной папки. Загружайте содержимое прямо в корень репозитория.
6. Commit message: Update Life RPG to 6.0 Final Life OS
7. Commit changes.
8. Подождите 1–3 минуты и откройте GitHub Pages.
9. Ещё → версия должна быть Life RPG 6.0.0 / data v12.

Первичная настройка после обновления:
- Финансы → Счета и реальные остатки: сверьте основной счёт и добавьте остальные счета/наличные.
- Финансы → Редактор долгов: проверьте остатки, ставки, минимальные платежи и даты.
- Финансы → Smart Budget: после накопления истории можно применить рекомендации.
- Работа → Work CRM: добавьте объекты и следующие шаги.
- Скриншоты банка: сначала импортируйте небольшую пачку и проверьте очередь.

Важно:
- OCR работает локально в браузере, но Tesseract.js и языковая модель загружаются из интернета. Всегда проверяйте распознанные суммы перед подтверждением.
- Модели процентов по долгам приблизительные, помесячные; фактический остаток периодически сверяйте с банком.
- Life RPG 6.0 — локальная PWA. Полноценная облачная синхронизация и настоящая биометрическая защита требуют отдельного backend/native-контура и не включены в статическую GitHub Pages-версию.
