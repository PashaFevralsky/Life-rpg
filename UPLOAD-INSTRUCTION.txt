Life RPG 10.0.2 — загрузка с телефона

1. В текущем приложении экспортируй резервную копию JSON.
2. Распакуй архив. Загрузи корневые файлы в корень существующего репозитория Life-rpg с заменой.
   Нужны все JS/HTML/CSS, конфигурации, package.json, package-lock.json, тесты, картинки и manifest.
   Архив ZIP целиком загружать вместо распакованных файлов не нужно.
3. Если телефон не показывает папку .github, открой существующий файл
   .github/workflows/deploy-pages.yml в GitHub и замени его содержимым
   корневого DEPLOY-PAGES-WORKFLOW.yml из этого архива.
   Если файл отсутствует, создай его с этим полным путём.
4. GitHub Pages: Source = GitHub Actions. Дождись зелёного завершения workflow.
5. Закрой все вкладки сайта и установленное приложение. Открой снова.
   В настройках должна отображаться версия 10.0.2.
6. При уведомлении о готовом обновлении закрой и открой приложение ещё раз.

Обновление кода не требует повторного импорта выписки или сброса данных.
Архив подготовлен и проверен локально. Публикацию выполняешь ты через GitHub.
Подробности изменений и проверки: CHANGELOG-10.0.2.txt и AUDIT-10.0.2.txt.
