Life RPG 5.2.1 Money Engine — загрузка на GitHub с телефона

ПЕРЕД ОБНОВЛЕНИЕМ
1. В текущем Life RPG откройте «Ещё» → «Экспорт JSON» и сохраните резервную копию.

ЗАГРУЗКА
2. Скачайте ZIP и распакуйте его на телефоне.
3. Откройте GitHub → PashaFevralsky/Life-rpg.
4. Проверьте, что выбрана ветка main.
5. Нажмите Add file → Upload files.
6. Выберите ВСЕ 8 файлов ИЗ распакованной папки, а не саму папку.
7. Файлы должны лежать в КОРНЕ репозитория и заменить старые.
8. Commit message: Update Life RPG to 5.2.1 Money Engine
9. Нажмите Commit changes прямо в main.
10. Подождите 1–3 минуты и откройте https://pashafevralsky.github.io/Life-rpg/
11. В «Ещё» проверьте версию Life RPG 5.2.1.

ПЕРВЫЙ ЗАПУСК 5.2.1
12. Откройте «Финансы» → «Реальный денежный баланс».
13. Введите фактическую сумму денег на обычных счетах + наличными, НЕ включая отдельный аварийный резерв.
14. Нажмите «Сверить денежный баланс».
15. Если аварийный резерв уже существует, укажите его отдельно в блоке «Отдельный резерв и финансовая фаза».
16. Только после этого нажимайте «Принять план» в Money Engine.

Не очищайте данные сайта без JSON-резервной копии: данные хранятся локально в IndexedDB браузера.
