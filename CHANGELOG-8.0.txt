Life RPG 8.0.0 — Core Refactor
=================================

BASE
----
Built from the already stabilized Life RPG 7.2.0 working tree.

ARCHITECTURE
------------
The old ~365 KB monolithic app.js runtime has been replaced by:
- core.js
- state.js
- finance.js
- imports.js
- work.js
- tennis.js
- knowledge.js
- gamification.js
- pwa.js
- ui.js
- bootstrap.js

app.js remains only as a tiny compatibility shim and contains no application logic.
No bundler or build step is required: GitHub Pages loads the scripts directly.

DUPLICATE CLEANUP
-----------------
The source was parsed with Acorn AST before refactoring.
- 61 obsolete FunctionDeclaration nodes removed.
- 50 duplicate function names eliminated.
- 472 unique top-level functions remain.
- No duplicate function declarations remain across runtime files.

DATA COMPATIBILITY
------------------
App version: 8.0.0
State schema: v16
The state schema is intentionally unchanged from 7.2.
Existing IndexedDB data is preserved; no additional migration is required.

BROWSER CHECK
-------------
A real Chromium smoke run was attempted in the container, but this Chromium build
did not complete headless DOM dumping in the environment. This is therefore not
claimed as a completed browser-E2E test. Runtime modules were executed sequentially
inside a shared Node VM context, and the static/regression suite passed.
