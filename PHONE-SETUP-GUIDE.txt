LIFE RPG 9.0.0 — НАСТРОЙКА ТОЛЬКО С ТЕЛЕФОНА

ВАЖНО: компьютер, Termux, Node.js и npm на телефоне не нужны.

ПЕРЕД ОБНОВЛЕНИЕМ
1. В Life RPG сделай обычную JSON-резервную копию.
2. Не удаляй установленную PWA и не очищай данные сайта.
3. Не импортируй годовую банковскую выписку повторно.

ШАГ 1. ЗАГРУЗИТЬ 9.0.0
Распакуй ZIP на телефоне и загрузи/замени файлы в корне репозитория Life-rpg.
Файл DEPLOY-PAGES-WORKFLOW.yml тоже загрузи в корень — он нужен для следующего шага.

ШАГ 2. ОДИН РАЗ СОЗДАТЬ WORKFLOW
На GitHub открой репозиторий -> Add file -> Create new file.
В поле имени файла введи ровно:
.github/workflows/deploy-pages.yml

Открой DEPLOY-PAGES-WORKFLOW.yml из корня репозитория, скопируй весь текст и вставь его в новый файл. Нажми Commit changes.

ШАГ 3. ПЕРЕКЛЮЧИТЬ GITHUB PAGES
GitHub -> репозиторий -> Settings -> Pages -> Build and deployment -> Source -> GitHub Actions.
Это делается один раз.

ШАГ 4. ДОЖДАТЬСЯ СБОРКИ
Открой вкладку Actions. Workflow “Build and deploy Life RPG” должен выполнить:
- npm install
- npm test
- npm run build
- публикацию dist в GitHub Pages

Если любой тест или Vite-сборка упадут, GitHub не опубликует повреждённую версию.

ШАГ 5. ОБНОВИТЬ PWA
После зелёного deployment полностью закрой Life RPG и открой снова.
Проверь: Life RPG 9.0.0, схема данных v16.

ПОСЛЕ ЭТОЙ ОДНОРАЗОВОЙ НАСТРОЙКИ
Для следующих версий процесс снова будет простым:
скачал ZIP -> распаковал -> заменил файлы в GitHub с телефона.
GitHub сам установит зависимости, прогонит тесты, соберёт Vite и опубликует приложение.
