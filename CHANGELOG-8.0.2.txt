===========================================

Base
----
Built on the published Life RPG 8.0.1.

Existing IndexedDB data is preserved.

UX findings fixed
-----------------
1. Today quick actions:
   - “Work” switched to the Work section but could leave the entry form hidden on Overview.
   - “Training” had the same problem in Tennis.
   Both actions now open the correct subview before focusing the form.

2. Money:
   - “Now” mixed decisions, bank OCR, reconciliation, imports and account maintenance.
   - Added a dedicated “Bank” subtab.
   - Bank OCR, reconciliation, account balances, import rules, import batches and CSV import
     are grouped there.
   - “Now” remains focused on current financial state and decisions.
   - Account management stays visible from both “Bank” and “Operations”.

3. Work daily entry:
   - The form exposed nine numeric fields at once on mobile.
   - Date, sales, contacts, follow-ups and LPR remain visible.
   - Meetings, proposals, wins and pipeline are placed under “Additional metrics”.
   - No field IDs or saved data model changed.

4. Tennis session entry:
   - The form exposed match fields even for ordinary technique/training sessions.
   - Core training fields remain visible.
   - Wins/losses/opponent/rating/score are now under “Match data — if games were played”.
   - No tennis state fields were removed.

5. Settings:
   - 15+ inputs were displayed as one uninterrupted wall.
   - Settings are grouped into Finance, Work, and Tennis/Reading disclosure sections.
   - Name and main goal stay immediately visible.
   - All original input IDs and save behavior are preserved.

6. Mobile touch targets:
   - Main buttons, section tabs, bottom navigation, inputs and selects have a 44px minimum
     touch height on mobile.
   - Disclosure groups received clearer open/closed affordances.

7. Dangerous zone:
   - The reset card now explicitly states that a local safety snapshot is created first.
