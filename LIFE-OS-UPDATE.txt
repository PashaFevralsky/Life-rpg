Life RPG — Life OS / Сегодня, первая глубокая итерация

Что изменено
- Единый cross-domain Decision Engine поверх Finance / Work / Tennis / Knowledge.
- Жёсткие обязательства (просрочки, кассовый разрыв, критичные данные,
  просроченные CRM-шаги) всегда выше мягких целей.
- Дневной план ограничивается 2–6 приоритетами; по умолчанию 4.
- После жёстких обязательств система старается не забивать весь день
  задачами одной области и добавляет другие области только при достаточном приоритете.
- Отдельно считается объём задач, сознательно оставленных вне плана.
- Есть оценка активного времени по типам действий.
- Knowledge: чтение и повторение объединяются в один блок, если нужны оба.
- Tennis: при высокой 7/28 нагрузке и критичных задачах в других областях
  тяжёлые теннисные действия автоматически понижаются в очереди.
- Guardrails объясняют ограничения: кассовый разрыв, высокая нагрузка,
  просроченная CRM, backlog повторений, перегрузка.
- "Минимально достаточный день": критичные обязательства + рабочий фокус +
  дневной минимум чтения, максимум 3 пункта.
- Старые Daily Engine и "Что сделать сегодня" теперь используют единый
  Life OS ranking, а не независимые списки.

Ручной ввод
- Новых обязательных полей нет.
- Единственная новая настройка: максимум приоритетов на день.

Совместимость
- Схема базы не меняется.
- Finance / Work / Tennis / Knowledge не изменяются.
- Изменяется только bootstrap.js.
- Life OS добавляется после загрузки всех основных модулей и до старта приложения.

Проверки перед выдачей
- node --check bootstrap.js
- новые динамические ID не обращаются через $("..."), поэтому static-check
  не должен считать их отсутствующими в index.html.
