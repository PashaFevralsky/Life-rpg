# Life RPG 14.0 — Android RC acceptance

Этот чек-лист выполняется на реальном телефоне. Автоматические JS/E2E тесты не заменяют эти проверки.

## Release blockers

- [ ] Обновление поверх последней Signed Beta без удаления приложения.
- [ ] Сохранность данных после обновления: финансы, задачи, настройки, Life Ops.
- [ ] Повторное обновление RC поверх предыдущего RC без потери IndexedDB.
- [ ] Холодный запуск приложения после принудительного закрытия.
- [ ] Офлайн-запуск в авиарежиме после хотя бы одного обычного запуска.
- [ ] Android-уведомление Life Ops приходит после полного закрытия приложения.
- [ ] После закрытия дня уведомления на этот день больше не приходят.
- [ ] Backup JSON создаётся.
- [ ] Restore/Import Backup восстанавливает данные и не создаёт дубликаты.
- [ ] Перед опасным импортом создаётся snapshot; rollback работает.
- [ ] Доход → Money Autopilot открывается и не создаёт двойной reservation.
- [ ] Баланс: на счетах = зарезервировано + свободно (+ отдельный резерв по правилам модели).
- [ ] Все 5 разделов: Сегодня / Деньги / Работа / Теннис / Ещё — без наложений status bar и bottom nav.
- [ ] Модальные окна помещаются на экран, закрываются Back/×, клавиатура не скрывает основное действие.
- [ ] После сворачивания и возврата состояние интерфейса и данные не теряются.

## Share Target в 14.0 RC

Native Android Share Target намеренно отключён и НЕ является заявленной функцией этого RC.

- [ ] Life RPG не появляется как принимающее приложение в системном Android «Поделиться».
- [ ] В Android RC не загружается `share-hub.js`.
- [ ] Ручные импорты через Import Hub / выбор файла продолжают работать.

Если native Share будет исправлен и отдельно принят на реальном телефоне, его можно вернуть в 14.1+.

## Решение по RC

RC считается готовым к Stable только если все release blockers выше отмечены PASS и нет известных дефектов, способных:
1. потерять/исказить данные;
2. дать неверное финансовое действие;
3. заблокировать запуск/обновление;
4. ломать ежедневные уведомления;
5. перекрывать критическое действие интерфейса.
