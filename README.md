# Life RPG 9.0.0

Mobile-first personal Life OS. Version 9.0.0 preserves state schema v16 and the 8.2 full visual redesign while adding a Vite/Workbox build pipeline, Zod import validation, Lucide icons and exact-cent financial aggregate helpers.

Deployment: GitHub Actions builds `dist` with Vite and deploys it to GitHub Pages. See `PHONE-SETUP-GUIDE.txt`.
