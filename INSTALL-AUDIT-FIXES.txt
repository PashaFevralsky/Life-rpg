База: 5a716d4 (Android 14.0.3 RC18, web 13.9.1).

1. Распакуй ZIP на телефоне.
2. Открой https://github.com/PashaFevralsky/Life-rpg в браузере.
3. В корне репозитория: Add file → Upload files.
4. Выбери все файлы из архива, кроме этой инструкции. Загружай сами файлы, не ZIP и не папку.
5. Подтверди замену одним коммитом. Название: Fix comprehensive audit 2026-10-04.
6. Во вкладке Actions дождись Build Life RPG Android RC для нового коммита.
   Изменение JS/package.json запускает его автоматически; не запускай второй параллельно.
7. Только после успешной сборки скачай APK из нового артефакта.
   Устанавливай поверх прежнего приложения, не удаляя его и не очищая данные.

Архив содержит исходники и тесты, не APK. Папку .github изменять не нужно.
