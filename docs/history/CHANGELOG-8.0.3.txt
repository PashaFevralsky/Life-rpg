HIGH-IMPACT ISSUES FIXED
------------------------
1. Overdue mandatory payments are now included in day-0 cash-flow projections,
   safe-to-spend calculations, Autopilot reserves and 30/90-day forecasts.
2. Editing debt metadata no longer falsely marks the debt balance as bank-verified.
3. Payment undo/reconciliation locking is isolated to the same debt.
4. Import historical cutoffs use the actual account's verification timestamp.
5. Negative calculated account balances are no longer hidden as 0 ₽.
6. Historical debt imports preserve the real payment amount and do not consume current reservations.
7. Debt payments can be attributed to their actual due period across month boundaries.
8. Large encrypted backups use chunked base64 encoding instead of a single huge spread operation.
9. A zero Work weekly target disables the quest instead of making 0 >= 0 instantly claimable.
10. Restoring deleted imported expenses restores reservation/compensation symmetrically.
11. Manually backdated income uses its occurrence date for historical-import logic.
12. ChatGPT action-package application creates a pre-action safety snapshot.
13. Explicit zero values remain valid for high-interest threshold and Tennis base Elo.
14. normalizeState preserves original created/updated timestamps and no longer fabricates
    debt verification timestamps from state.updated.
15. Creating an account with a blank starting balance creates an unverified account;
    explicit 0 still creates a verified zero balance.

ADDITIONAL CONSISTENCY FIXES
----------------------------
- Fixed-loan stale dates project the next estimated recurring payment.
- Same-day future planned income no longer eliminates today's living reserve.
- Primary-account verification is used by Money Engine/Autopilot.
- Snapshot cards show their real safety labels.
- “Open bank import” opens the dedicated Bank view.
- Tesseract.js is pinned to exact v5.1.1 instead of floating @5.

BROWSER TEST LIMITATION
-----------------------
A real Chromium 144 headless run at 390×844 was attempted against a local HTTP server.
The container Chromium did not complete DOM dumping because the environment lacks required
DBus/zygote facilities. A browser-E2E pass is therefore NOT claimed.

KNOWN NON-BLOCKING PRODUCT LIMITATIONS
--------------------------------------
- No cloud sync; cross-device transfer is via backup.
- Background notifications are not guaranteed while the PWA is fully closed.
- OCR requires internet and an external Tesseract.js CDN resource.
- Internal Tennis Elo is a Life RPG metric, not an official federation rating.
- Debt interest/payoff scenarios are estimates rather than bank amortization statements.
- Life Score is a heuristic dashboard metric.
- The exact IndexedDB state on the user's phone cannot be inspected remotely.

8. Do NOT re-import the annual bank statement.
