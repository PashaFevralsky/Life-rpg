Life RPG — Work OS, первая глубокая итерация

Что изменено
- Work Command Center: факт, остаток до плана, требуемый темп, прогноз.
- Pipeline Engine: сырая и взвешенная воронка на текущий месяц.
- Расчёт требуемой сырой воронки для покрытия остатка плана.
- Два независимых сценария прогноза:
  1) по вероятностям каждой CRM-сделки;
  2) по единой исторической/базовой конверсии.
- Историческая конверсия используется только после минимального числа закрытых сделок.
  До этого применяется задаваемая базовая гипотеза.
- CRM Hygiene: просроченные следующие шаги, отсутствие следующего шага,
  отсутствие даты закрытия, просроченная дата закрытия, устаревшие сделки,
  неполные карточки сделок >=500 тыс. руб.
- Decision Engine: формирует конкретный список действий по текущим данным.
- Контроль недельной активности против целей.
- Факт продаж и новая CRM-воронка за последние 6 месяцев.
- Аналитика проигранных сделок по фактически заполненным причинам.
- Scenario Lab: "что если" для конверсии и дополнительной воронки.
- Настройки Work OS прямо в разделе Работа:
  месячный план, базовая конверсия, минимальная выборка,
  порог устаревания сделки и недельные цели активности.

Принципы расчёта
- Факт продаж берётся только из workLogs.
- В месячную прогнозную воронку входят только открытые сделки,
  у которых closeDate относится к текущему месяцу.
- Взвешенный прогноз = сумма potential * probability по таким сделкам.
- Требуемая сырая воронка = остаток до плана / используемая конверсия.
- Историческая конверсия = выигранные / все закрытые CRM-сделки.
- При недостаточной выборке используется базовая гипотеза из настроек.
- Проценты между рабочими активностями не называются конверсией,
  потому что контакты, ЛПР и КП могут относиться к разным сделкам.
- Прогнозы обозначены как модели, а не как гарантированный результат.

Совместимость
- Схема данных не менялась.
- Финансовый модуль не изменялся.
- Старые данные Work/CRM сохраняются.
- Новые настройки хранятся в существующем объекте settings.
- Исходные функции Work/CRM сохранены; глубокий слой добавлен поверх них.

Проверка перед выдачей
- node --check work.js: OK
- Отдельные тесты формул Work OS: OK
  * fallback-конверсия
  * переход на историческую конверсию
  * требуемая воронка
  * CRM diagnostics
  * сценарный прогноз

Как загрузить
1. Сделай резервную копию JSON в Life RPG.
2. Замени только корневой файл work.js файлом из этого архива.
3. Commit в main запустит GitHub Actions автоматически.
4. После успешного deploy полностью закрой PWA и открой заново.
5. В разделе Работа после верхней карточки появится Work OS.

Если GitHub Actions упадёт — не переимпортируй данные и не очищай PWA.
Сначала нужно посмотреть конкретный лог.
